# 企业端项目管理

## 项目概览

在智汇平台中，企业发布的需求会转化为项目进行管理。企业端提供完整的项目管理功能，帮助您高效跟踪和管理项目进展。

## 项目状态管理

项目共有5种状态：审核中、审核失败、进行中、已完成、已暂停。

- **审核中**：项目提交后，进入审核阶段，等待相关负责人或评审团队的审批
- **审核失败**：项目在审核过程中未通过，未能获得批准
- **进行中**：项目通过审核后，正式进入实施阶段
- **已完成**：项目所有任务和目标都已成功完成，达到预期效果
- **已暂停**：项目在执行过程中因某些原因暂时停止

## 项目操作

您可以进行以下项目操作：

- **查看项目详情**：点击项目可查看详细信息，包括需求描述、项目状态等
- **编辑项目**：通过"编辑"按钮更新项目信息
- **暂停/删除项目**：对"进行中"状态的项目可进行暂停或删除操作

## 项目统计与分析

通过数据可视化功能，您可以直观查看项目发布和执行情况，包括项目状态分布、执行进度等统计信息，帮助您更好地进行项目规划和资源分配。
