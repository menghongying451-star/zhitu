# 企业端团队管理

## 团队概览

用户**查看团队成员数量、设置团队成员权限、审核团队成员进入**，可进入【企业设置】，点击【团队管理】，管理自己的企业团队。

![img](/docs/picture/四_企业端企业成员管理.png)

## 团队成员管理

点击"编辑"按钮，可对团队成员审核状态、团队权限等进行修改。

### 团队权限等级

团队权限包括：拥有者、管理员、成员、待分配。

- **拥有者**：一个企业或机构有且仅有一位拥有者，对团队拥有最终控制权
- **管理员**：比拥有者低一层级的是管理员，负责管理团队的日常运营和成员权限
- **成员**：主要负责完成分配的任务和参加团队活动
- **待分配**：为已加入团队但尚未被分配具体权限的成员，通常需要等待拥有者或管理员分配权限

![img](/docs/picture/四_企业端企业成员权限.jpg)

## 团队管理功能

1. **成员审核**：审核新成员加入团队的申请
2. **权限分配**：根据成员职责和贡献分配适当的权限
3. **团队信息维护**：更新团队基本信息和联系方式
4. **团队活动管理**：组织和管理团队内部活动，促进团队协作

通过有效的团队管理，您可以确保企业内部协作高效有序，提高团队整体执行力和创新能力。
