# 学生端项目匹配与申请

## 筛选需求

### 智能体推荐

在【企业需求总览】，通过与智能体对话，智能体明确学生的兴趣与技能，自动推荐项目。

![img](/docs/picture/三_学生端企业需求总览智能体.png)

### 标签筛选

学生手动输入并选择兴趣与技能后，系统为学生匹配满足要求项目。

![img](/docs/picture/三_学生端手动输入标签.png)

## 需求了解

在左侧面板的【需求关注】里，点击某一项目，在【需求介绍】中简要了解项目。

![img](/docs/picture/三_学生端需求总览.png)

在【项目组队】，以便揭榜挂帅（创建项目）。

![img](/docs/picture/三_学生端组队.png)

点击【企业资源】，以便查看/下载该需求的相关资源。

![img](/docs/picture/三_学生端企业资源.png)

点击【智能体问答】，与智能体交互，以了解该需求的详细信息。

![img](/docs/picture/三_学生端智能体问答具体项目.png)
