# Django管理员系统广播功能使用指南

## 功能概述

系统广播功能允许管理员通过Django管理后台向所有用户或特定用户群体发送重要通知，支持多种广播类型和发送策略。

## 功能特性

### 📢 广播类型
- **系统公告**: 一般性系统公告和重要信息
- **维护通知**: 系统维护、升级相关通知
- **版本更新**: 系统版本更新和新功能介绍
- **紧急通知**: 紧急情况和重要警告

### 👥 目标用户
- **所有用户**: 向所有活跃用户发送
- **仅活跃用户**: 向最近30天内登录的用户发送
- **仅管理员**: 向管理员用户发送

### ⚡ 发送策略
- **WebSocket**: 实时推送（默认启用）
- **邮件通知**: 可选择同时发送邮件

### ⏰ 通知管理
- **优先级设置**: 普通、高、紧急
- **有效期控制**: 1-168小时（最多7天）
- **发送统计**: 实时显示发送成功率

## 使用步骤

### 1. 进入管理后台
访问Django管理后台：`/admin/`

### 2. 导航到通知管理
1. 登录管理后台
2. 点击 "通知详情" 模块
3. 在通知列表页面顶部，点击 "发送系统广播通知" 按钮

### 3. 填写广播内容

#### 基本信息
- **广播类型**: 选择合适的广播类型
- **通知标题**: 简洁明了的标题（最多200字符）
- **通知内容**: 详细的通知内容

#### 发送设置
- **优先级**: 根据重要程度选择
  - 普通：一般信息
  - 高：重要信息
  - 紧急：需要立即关注的信息
- **有效期**: 设置通知的有效时间（1-168小时）
- **目标用户**: 选择接收通知的用户群体
- **同时发送邮件**: 可选择是否通过邮件同时发送

### 4. 发送广播
点击 "发送系统广播" 按钮完成发送

## 使用示例

### 示例1：系统维护通知
```

通知标题: 系统维护通知 - 2024年1月15日
通知内容: 
尊敬的用户，

优先级: 高
有效期: 48小时

同时发送邮件: ✓
```

## 发送结果

发送完成后，系统会显示：
- ✅ **成功**: "系统广播发送成功！共发送给 X/Y 个用户"
- ❌ **失败**: "系统广播发送失败，请检查通知类型配置"
- ⚠️ **错误**: 具体的错误信息

## 注意事项

### ⚠️ 重要提醒
1. **谨慎使用**: 系统广播会发送给大量用户，请确保内容准确
2. **内容审核**: 发送前请仔细检查标题和内容
3. **频率控制**: 避免频繁发送，以免影响用户体验
4. **权限管理**: 只有管理员才能发送系统广播

### 📋 最佳实践
1. **标题简洁**: 使用清晰、简洁的标题
2. **内容结构化**: 使用列表、分段等方式组织内容
3. **时间明确**: 涉及时间的通知要明确具体时间
4. **联系方式**: 重要通知应提供联系方式
5. **测试发送**: 重要通知可先发送给管理员测试

### 🔧 故障排除

**问题**: 发送失败
**解决方案**:
1. 检查通知类型是否已正确配置
2. 确认目标用户群体不为空
3. 检查系统日志获取详细错误信息

**问题**: 用户未收到通知
**解决方案**:
1. 检查用户的通知偏好设置
2. 确认用户在目标群体范围内
3. 检查WebSocket连接状态

## 技术支持

如遇到问题，请：
1. 查看系统日志：`/admin/notification/notificationlog/`
2. 检查通知配置：`/admin/notification/notificationtype/`
3. 联系技术支持团队
